# References

- `keel.json`: the bibliography, in CSL-JSON. One entry per work or dataset cited on the site. Keys are the first author's surname (or an organization word) plus the year, with a letter when the same authors have two works in a year (`kulveit2025`, `herdagdelen2026a`); datasets use descriptive keys (`bls_labor_share`). Entries of type `dataset` form the "Data sources" section of the Sources page; all others form "References". Each entry is verified against its original before it is added (`review/sources-verification.md`).
- `chicago-author-date-17th-edition.csl`: the official Citation Style Language style for Chicago Manual of Style 17th edition (author-date), downloaded on 2026-11-18 from https://raw.githubusercontent.com/citation-style-language/styles/master/chicago-author-date-17th-edition.csl (styles repository commit e5c42aca616b16fa41e1512fcf4103072c1e5f2f; the style's `<updated>` is 2025-02-09). The repository's `chicago-author-date.csl` is now the 18th edition, so the 17th-edition file is used, as the owner chose. It is kept for in-text citations through Quarto.

The Sources page (`site/sources.qmd`, generated part `site/_generated/sources.md`) is rendered by `indicators.bibliography`, which applies Chicago author-date rules directly (see its docstring) so that every entry gets an anchor equal to its key and the two sections stay separate. Run `python -m indicators.pages` to rebuild it, and `python -m indicators.bibliography check-links` to check every URL and DOI (writes `review/sources-link-check.md`).
